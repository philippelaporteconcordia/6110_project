A Secure Peer-to-Peer Messaging System providing a framework for TCP communications similar to TLS.

Acccessible as a command-line interface (CLI) that ensures confidentiality, integrity, and authentication of messages. The system utilizes hybrid 
asymmetric encryption, where RSA is used for key exchange and AES 128 in CBC mode for actual communication. RSA digital signatures and HMAC 
authentication are used to provide message integrity and authenticity. Delivers Perfect Forward Secrecy of the RSA keys as an alternative 
to Certificate-based Authentication.

A project report and a presentatiion complement the code.
